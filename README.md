# Akshayraj Portfolio — GitHub Online APK Build (2026)

Modern Android WebView portfolio app. Includes the supplied photo gallery, video gallery, Instagram link, About section and WhatsApp contact.

## Build APK online from GitHub
1. Extract this ZIP.
2. Upload **all files and folders** from the extracted directory to the root of your GitHub repository. Include the hidden `.github` folder.
3. Commit changes to the `main` branch.
4. Open **Actions** → **Build Akshayraj Portfolio APK** → **Run workflow**.
5. When the run completes successfully, download the `Akshayraj-Portfolio-APK` artifact.
6. Extract the artifact ZIP and install `app-debug.apk`.

Build uses Android Gradle Plugin 9.4.0, Gradle 9.6.0, JDK 17 and Android SDK 37. It is configured for GitHub's cloud runner, not the old AndroidIDE environment.
